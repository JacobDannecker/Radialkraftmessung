# Software begleitend zu einer Bachelorarbeit an der Hochschule Mannheim:
## Titel
Implementierung einer Software und
Messtechnik zur Ermittlung von
Radialkräften an Wellendichtringen
in Abhängigkeit der Temperatur

## Kurzfassung
Die Temperatur eines Werkstoffs beeinflusst dessen Eigenschaften. Bei Radialwellen-
dichtringen verändern sich dadurch die radial wirkenden Kräfte und damit die Dichtei-
genschaften. In der vorliegenden Arbeit wurde eine bereits vorhandene Prüfeinrichtung
überarbeitet und erweitert. Die Prüfeinrichtung dient zum Messen der Radialkräfte,
welche Wellendichtringe ausüben. Dabei kann die Prüfkammer erwärmt werden, um
den Einfluss der Temperatur auf die Radial wirkenden Kräfte zu ermitteln. Aus der
vorhandenen Prüfeinrichtung wurde lediglich die Aufspannvorrichtung für die Dichtringe
übernommen. Die gesamte Elektrik wurde erneuert und neue Messtechnik eingebaut.
Die jetzige Prüfeinrichtung ist mit einem Einplatinencomputer versehen, auf dem eine
eigens für die Aufgabe entworfene grafische Anwendung läuft, sodass zum Betrieb nur ein
Anzeigegerät und eine Computermaus notwendig sind. Es wurde eine Möglichkeit zum
Exportieren der Messdaten geschaffen, die zudem in Echtzeit in einem Plot dargestellt
werden können.

## OS
Raspberry Pi OS getestet

## Features
- Echtzeitdarstellung von Temperaturen und Kräften
- Automatische Regelung der Temperatur in der Prüfkammer (Zweipunktregler)
- Tarierung der Sensoren
- Statusanzeige Temperaturregelung
- Export der Daten auf angeschlossene Datenträger
- Kein zusätzlicher Rechner erforderlich; lediglich Bildschirm und Maus, gegebenenfalls eine Tastatur (alternativ via SSH)
- Bootet direkt in die Benutzeroberfläche
